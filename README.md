## 1. Project Overview
Build X is a responsive, multi-page website designed for a fictional custom PC and hardware retailer in South Africa. The site showcases pre-built gaming computers and individual PC components, featuring dynamic JavaScript filtering, product search, interactive form validation, and comprehensive SEO integration.

## 2. Website Goals & Objectives
*   Present PC products and components in a clear, browsable catalog.
*   Provide a seamless user experience across desktop, tablet, and mobile devices.
*   Implement dynamic functionality (product search, category filtering, and image lightboxes).
*   Capture user enquiries and contact requests using client-side validated forms.

## 3. Sitemap
*   Home (`index.html`)
*   Pre-Built PCs (`products.html`)
*   Components (`components.html`)
*   Enquiry Form (`enquiries.html`)
*   Contact (`contact.html`)

## 4. Key Features & Functionality
*   **HTML5 & Semantic Structure:** Consistent navigation and layout across all pages using appropriate semantic tags.
*   **CSS3 & Responsive Design:** A dark-tech themed UI built using CSS variables, Flexbox, and CSS Grid. Media queries ensure the layout adapts seamlessly to mobile devices without horizontal scrolling.
*   **JavaScript Interactivity:**
    *   Dynamic product search and category filtering on the components page.
    *   Custom interactive lightbox for viewing product images.
    *   Comprehensive client-side form validation for both enquiry and contact forms with inline error messaging.
    *   URL parameter integration (clicking "Enquire" on a specific product automatically fills out the enquiry form).
*   **SEO:** Optimized meta descriptions, keywords, and descriptive image `alt` text implemented across all pages.

## 5. Timeline & Milestones
*   **Part 1:** Project initiation, research, and foundational HTML structure.
*   **Part 2:** CSS styling, responsive layouts, and visual design.
*   **Part 3:** JavaScript functionality, SEO integration, form validation, and final deployment.

## 6. Feedback Addressed (Part 2 to Part 3)
Based on the feedback received in Part 2, the following comprehensive updates were made:
1.  **Dedicated Enquiry Page:** A separate `enquiries.html` page was created and linked across the site to distinguish product-specific enquiries from general contact messages.
2.  **Mobile Responsiveness:** Fixed horizontal text overflow on mobile with a 768px body overflow guard, wrapping contact headings, and responsive typography and layouts.
3.  **README Refactoring:** The documentation was streamlined to be professional, concise, and strictly aligned with the project rubric.
